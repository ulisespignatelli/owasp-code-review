# OWASP API Security Top 10 2023 aplicado a la revisión de código

Usalo además de la lista principal cuando el proyecto expone una API (REST, GraphQL, gRPC). Lista
oficial: https://owasp.org/API-Security/editions/2023/en/0x11-t10/ — la guía de revisión es propia.

| ID | Riesgo | Qué buscar en el código |
|---|---|---|
| **API1:2023** | Autorización rota a nivel de objeto (BOLA) | Endpoints con IDs de objeto que no verifican que el objeto pertenezca a quien pregunta. Mirá también IDs dentro del cuerpo y en consultas GraphQL anidadas. |
| **API2:2023** | Autenticación rota | Endpoints sin autenticación por error, tokens que no se validan (firma, vencimiento, audiencia), claves de API en la URL, recuperación de contraseña sin límites. |
| **API3:2023** | Autorización rota a nivel de propiedad | La respuesta devuelve el objeto completo (`return user` con `password_hash`, `is_admin`), o la actualización acepta cualquier campo (asignación masiva). Buscá serializadores sin lista de campos. |
| **API4:2023** | Consumo de recursos sin restricción | Sin paginación máxima (`?limit=1000000`), sin límite de tamaño de carga, consultas GraphQL sin límite de profundidad o costo, operaciones que disparan SMS/correos/pagos sin límite. |
| **API5:2023** | Autorización rota a nivel de función | Endpoints administrativos (`/admin/*`, `DELETE`, `PUT` sobre recursos ajenos) accesibles para usuarios comunes porque solo se ocultan en la interfaz o porque el chequeo de rol falta en un método HTTP. |
| **API6:2023** | Acceso sin restricción a flujos de negocio sensibles | Compras, reservas, registros o canjes automatizables sin control (sin límite, sin detección de bots), que permiten acaparar o abusar. |
| **API7:2023** | Falsificación de peticiones del lado del servidor (SSRF) | La API descarga o consulta URLs enviadas por el cliente (importar desde URL, webhooks configurables, vistas previas). |
| **API8:2023** | Configuración de seguridad incorrecta | CORS permisivo, métodos HTTP innecesarios, mensajes de error detallados, TLS ausente, cabeceras faltantes. |
| **API9:2023** | Gestión incorrecta del inventario | Versiones viejas de la API todavía activas (`/v1/` sin los controles de `/v2/`), endpoints de prueba o depuración desplegados, documentación interna expuesta. |
| **API10:2023** | Consumo inseguro de APIs | Respuestas de APIs de terceros usadas sin validar (se confían como si fueran internas), redirecciones seguidas a ciegas, sin tiempos de espera. |

## Pistas para GraphQL

- Introspección habilitada en producción (informativa por sí sola, útil para un atacante).
- Resolvers que no repiten la autorización: proteger la consulta raíz no protege los campos anidados.
- Consultas en lote o alias que permiten fuerza bruta en una sola petición.
- Sin límite de profundidad, de complejidad ni de tiempo.

## Pistas para gRPC y mensajería

- Servicios internos que asumen que "solo los llaman otros servicios" y no autentican.
- Mensajes de colas deserializados sin validar el esquema.
